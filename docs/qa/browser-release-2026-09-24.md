# 阅读体验修订与发布验收 · 2026-09-24

本轮在既有原生静态网站上修订内容组织与读数表达，未另写数据管线或改变研究判断。已发布并用真实 Chromium 验证：[网站](https://lawrence35952563.github.io/National-Power/)。

## 实际改动

- 导航改为研究导读、综合排名、八个领域、实体比较、数据与方法。宽表、字段、方法和下载集中在资料入口，旧分享路由仍可使用。
- 首页先解释长期行动能力的研究问题，再以“综合位置 → 能力结构 → 比较与依据”串起阅读；日本例子从当前数据层取值，不写死国家数字。
- 新增八领域导读与八个领域解释页，共 24 个具体主题、99 个真实字段链接。三个分组只组织阅读，不是新的统计层级或因果算法。
- 综合排名默认精简，领域与计算参考按需展开。实体页分开三项领域名次、五项基础条件，领域卡展开当前实体的明细，进入原表仍保留实体筛选。
- 比较和字段页不再将名次画成长条；基础评分使用固定 1–5 等级，小数评分保留原值。补充标记不进入正常刻度，politics-B 等其他得分不冒充基础评分。
- 没有证据的单位、年份和来源不生成空元信息卡。公式、审计和完整解释可展开；错误、空白、复合记录等有意义的限制继续就近说明。
- 下载页提供单文件离线版。构建器嵌入同一份导读，并按内容哈希为页面脚本与样式生成资源版本，解决旧访客缓存导致新旧页面混用的问题。
