# 来源与方法

本项目把国家与其他评价实体的经济、军事、人口、资源和基础设施放在同一框架中比较，关注它们在长期压力下组织资源、持续行动的能力。排名是作者研究判断的结构化表达，阅读时应结合领域结构和梯队。

## 数据依据

网站以本次发布所附 Excel 为唯一数值来源。排名、领域结果、底层数值和公式参考值均由同一份工作簿转换；历史报告只用于补充指标含义。原表数据不会在建站过程中被外部数字替换，检查发现的问题保留在质量报告中。

## 八个领域

| 领域 | 关注内容 | 读数方式 |
| --- | --- | --- |
| 军事 | 海军、空军、陆军与长期国防动员 | 原表排名越小，位置越靠前 |
| 经济 | 产出、资产与资本积累、人口就业和增长 | 原表排名越小，位置越靠前 |
| 政治 | 人口质量、科研、工业、外交、金融与企业网络 | 原表排名越小，位置越靠前 |
| 矿产 | 工业原料覆盖、自给和外部依赖 | 领域评分越大，供给条件越充分 |
| 农业 | 粮食、水、纤维和木材等基础供给 | 领域评分越大，供给条件越充分 |
| 能源 | 油气煤供给、储量、消费与替代电力 | 领域评分越大，供给条件越充分 |
| 交通 | 人员、物资和信息的连接及运输效率 | 领域评分越大，基础条件越充分 |
| 稳定 | 持续组织资源、自我控制和应对压力的条件 | 领域评分越大，基础条件越充分 |

此处名称沿用当前 Excel。“政治”字段覆盖的内容较广，“稳定”另行衡量内部组织和承压条件；两者应结合具体指标阅读。

## 如何阅读结果

原表最终名次与公式参考值分别展示。工作簿同时保留统计数值、计算公式和作者判断，最终名次不完全等同于公式参考值的机械排序。网站沿用最终名次，不重新设权或改写研究结论。

五个基础条件领域以 1–5 为主要评分尺度：1 为明显短缺，2 为依赖外部条件，3 为够用，4 为基本完整且单项优秀，5 为充足且有余量。特殊实体的小数名次和小数评分按原表保留。排名的名次差不代表能力差的固定倍数。

欧盟等特殊评价实体按原表单列；其数值不能简单理解为成员国资源完全统一调度。相同指标在不同地理和战略环境下的含义，可能由作者在最终判断中调整。

## 口径与估计

各指标的单位、年份、来源和说明以工作簿实际记录为准；缺少记录的地方标为未注明。历史报告的观察基准约为 2024 年底至 2025 年，部分资料更早，人口前景包含未来年份。这不表示各列均为同一年数据。

交通中的有效国土面积含作者估算；部分军事字段用小数部分编码第二项数量，不能把整格当成普通连续数值。网页保留这些原始记录及说明。空白、零值和公式错误分别保留含义，不统一替换成零。

## 来源说明

指标详情优先展示 Excel 内已有的来源和链接。背景报告另列 IMF、World Bank、CIA、Wikipedia、Trading Economics、Global Firepower、CSIS、FAO、EIA、World Mining Data、SIPRI、ITU、WID、UNIDO、Penn World Table、Flight International、ESA、USDA、UBS、TOP500 及各国官方机构作为参考来源。这份总清单不表示每个单元格均已逐一对应到原始出处。

## 当前边界

各国统计口径与年份可能不同，部分军事及资源信息存在估计或缺失。人工调整的完整依据未全部编码为可自动执行规则；网站的数据核对验证转换和呈现是否忠实，不能证明每项原始统计及每个研究判断都已获独立验证。具体问题和原表位置见本次质量报告。

本页描述随数据字典与质量报告维护，所有实体、指标数量和版本信息以当前发布数据层为准。
