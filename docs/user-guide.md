# 使用与更新说明

[打开国家长期能力综合排名网站](https://lawrence35952563.github.io/National-Power/)。平时看网站；更新数字时，只替换一份 Excel。

## 查找、比较与查看解释

| 想做什么 | 操作 |
| --- | --- |
| 找一个国家 | 在首页搜索名称，或打开“综合排名” |
| 看一个国家的详细记录 | 点击实体名称，先看领域结果，再选领域查看指标 |
| 比较几个国家 | 在排名中加入比较，或直接打开“实体比较” |
| 查一个指标 | 页面底部打开“指标目录”，也可从研究说明中的领域进入 |
| 像 Excel 一样看原表 | 打开“完整数据”，选择工作表 |
| 看定义、口径或公式 | 点击数字或展开对应说明；完整方法在页面底部“来源与方法” |
| 保存 Excel 或 CSV | 打开页面底部“下载” |

### 排名与实体页

综合排名可切换简单榜单和领域总览，也可单独显示公式参考值。搜索和筛选不会清空已加入比较的实体。

实体页分别展示三项领域名次和五项基础评分。通过领域定位查看具体记录，未记录项和辅助项仍可展开。点击数字可以看到原单元格、公式及已收录的解释。

政治、经济、军事的名次数值越小，位置越靠前；其余五领域主要用 1–5 级评分。名次之间的差距不表示能力倍数。小数名次和小数评分按原表保留；补充实体中的特殊标记不套用正常评分。

### 比较与完整数据

比较支持最多 5 个实体、8 个原字段。先看八领域总览，再按关键词、工作表或主题选择具体指标。组合字段会展开成分项，因此显示行数可能多于所选原字段数。切换筛选保留已选字段。

完整数据可以按主题显示一组列，也可以搜索列名后自行勾选。上方搜索查实体或单元格内容，列选择器中的搜索只查列名。选择“恢复完整原表”可查看全部列和辅助行。手机上左右滑动表格，名称列和表头保持可见。

### 返回与分享

首页搜索输入也保存在网址中，返回或刷新后仍保留；空白提交进入正式排名。浏览器后退恢复此前的筛选、排序、展开内容和浏览位置；顶部导航打开该栏目的默认视图。筛选与选择保存在网址中，可以直接分享；比较页也有复制链接按钮。接收者不会继承你的滚动位置。

### 说明来自哪里

数值和研究结果来自当前 Excel，说明整理自《综合国力2.0》PDF。旧报告的“发展”对应当前“政治”，旧“政治”对应当前“稳定”。网站使用 Excel 名称，并在报告释义中标注实际 PDF 页码。

只显示原材料有明确记录的单位、年份和来源。未显示表示未注明，不能据此认定所有字段是同一年。工作簿保存日期也不等于指标的观测年份。

## 更新数据

**需要替换的文件：[`data/source/national-power.xlsx`](../data/source/national-power.xlsx)。**

1. 在自己的 Excel 中修改数字、排名或评分，让公式完成重新计算并保存。
2. 准备名为 `national-power.xlsx` 的公开副本。保留现有工作表名称和表头，清理不准备公开的文档作者等个人属性。维护者也可用仓库现有导入程序代为完成。
3. 打开 GitHub 的 [`data/source` 文件夹](https://github.com/Lawrence35952563/National-Power/tree/main/data/source)，确认分支为 `main`。
4. 选择 **Add file → Upload files**，上传并替换同名文件，然后 **Commit changes**。
5. 在 [Actions](https://github.com/Lawrence35952563/National-Power/actions) 等待最新一次 **Validate, build and deploy Pages** 的 `build` 和 `deploy` 都成功，再刷新网站。

无需修改网页、JSON、CSV 或每个国家的页面。网站和下载文件都会自动使用新 Excel。

### 改一个数字时

修改 Excel 对应单元格即可。如果该数字改变后，你也希望修改人工录入的综合名次或领域评分，需要在同一份 Excel 中同步修改这些研究结果。网站不会替作者重新判定排名。

军事中用点号组合记录的字段仍来自原单元格，网页按现有规则分项显示。不要通过增加显示小数位来恢复已经丢失的尾零；原记录含义不明确时，先保留原值并交维护者核对。

### 哪些修改需要维护者处理

新增或删除工作表、改表头、拆列、改变权重与公式，或修订研究定义，需要同步检查数据映射和说明。你只需提供新版原件和研究意图，不需要自己修改配置或代码。

## 更新没成功怎么办

Actions 红叉表示失败。检查失败时，新版本不会覆盖上一次成功发布的网站。

打开失败运行，保留带红叉步骤的提示或运行链接，交给维护者。需要详细检查记录时，可在该次运行的 **Artifacts** 下载 `validation-and-build`。不必自己逐条理解程序报错。

如果全部成功但页面仍旧，先刷新，再核对下载页的数据版本和网站构建日期；仍有疑问时提供这两个日期和 Actions 链接即可。

原表中的空白、零和错误分别保留。数据异常见[检查记录](qa/excel-audit.md)，网站验收和发布结果见[发布状态](deployment-status.md)。

## 离线使用

在下载页保存单文件离线版，直接打开该 HTML 文件即可浏览。只需保留这一个文件，无需复杂文件夹；离线副本使用下载时的数据，不会自动跟随网站更新。

其他源码目录由维护者处理，说明见 [README](../README.md#目录)。
